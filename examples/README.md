# Examples

`jewellery-saas.architecture.json` is the canonical walkthrough design, produced by ArchitectFlow's
**example mode** (deterministic templates, not an AI) from this vision:

> Build a multi-tenant jewellery management SaaS with inventory, billing, branch management,
> offline synchronization, role-based access, PostgreSQL, and an administrative dashboard.

followed by "Propose pages" in the UI/UX workspace. Import it from **Versions & exports → Import
architecture JSON**. Generated tables, endpoints and non-functional requirements are labeled as
assumptions in the file — review them before treating them as a specification.
